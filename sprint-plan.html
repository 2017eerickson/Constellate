Constellate MVP Sprint Plan

Sep 10, 2026 - Dec 12, 2026 | 7 Sprints (2 weeks each) | 4 hrs/day with Claude Code building

Sprint Process (Do This Every Sprint)

  • Daily standup (5 min): What did I do yesterday? What's today? What's blocking me?
  • Sprint planning (Day 1, 30 min): Review upcoming tasks, adjust based on last sprint
  • Sprint review (Last day, 30 min): Demo what you built, note what's working and what isn't
  • Retrospective (Last day, 15 min): What went well? What slowed me down? What will I change?
  • Velocity tracking: Count completed tasks per sprint — if consistently finishing <80%, reduce scope
  • Definition of Done: Works locally, manually tested, no console errors
Size Estimates (with Claude coding): S = under 1 hr M = 1-2 hrs L = 2-4 hrs

Sprint 1: Partnerships Backend + Connect Flow Sep 10 - Sep 24
Sprint Goal: Two users can connect via partner codes and see each other in a partners list.

Week 1 — Backend

Day 1-2: Partnership API Endpoints
  • POST /api/v1/relationships/connect/ — accept partner_code, create pending partnership M
  • GET /api/v1/relationships/ — list all partnerships (pending, active, paused) S
  • PATCH /api/v1/relationships/<id>/ — accept, pause, or end a partnership M
  • DELETE /api/v1/relationships/<id>/ — remove/decline a partnership S
Day 3: Serializers + Validation
  • PartnershipSerializer — return partnership with nested partner info M
  • ConnectSerializer — accepts partner_code, looks up user S
  • Validate: no self-partnering, no duplicates, only partner can accept M
Day 4: URLs + Wiring
  • Create relationship_app/urls.py and register in main urls.py S
  • Add IsAuthenticated permission classes S
  • Test all endpoints via Postman/curl M
Day 5: Edge Cases + Tests
  • Handle invalid partner_code, already-connected, permission errors M
  • Write Django tests for each endpoint L

Week 2 — Frontend

Day 6-7: Partners List Screen
  • Create PartnersScreen — fetch and display all partnerships M
  • Show partner name, "days in orbit", relation type, status badge M
  • Pull-to-refresh S
  • Bottom tab navigation (Constellation, Partners, Settings) M
Day 8: Connect Flow
  • Add partner screen with text input for partner_code M
  • Submit calls connect endpoint, shows success/error M
  • Display your own partner_code with copy button S
Day 9: Incoming Requests
  • Pending partnerships with Accept/Decline buttons M
  • Visual distinction between sent vs received requests S
Day 10: Polish
  • Loading/error/empty states on all new screens M
  • End-to-end test: share code -> enter code -> accept -> both see active M
Sprint 1 Review (Sep 24)
